# Escopo do Projeto MESAFARTAI

## 1. Problema de negócio

Diariamente, alimentos próprios para consumo são descartados por
feirantes, supermercados, restaurantes e produtores devido à
proximidade da data de validade, pequenos defeitos estéticos ou
excesso de estoque.

Ao mesmo tempo, ONGs, abrigos e cozinhas comunitárias enfrentam
dificuldades para obter alimentos suficientes para atender pessoas
em situação de vulnerabilidade.

O MESAFARTAI busca solucionar esse problema utilizando tecnologia
para facilitar a comunicação entre doadores e organizações que
necessitam de alimentos.

A aplicação permitirá que o doador envie mensagens pelo chat,
informando os alimentos disponíveis. O sistema poderá identificar
informações como tipo de alimento, quantidade e validade, facilitando
o processo de doação e o direcionamento para uma ONG.

## 2. Público-alvo

### Doadores

São estabelecimentos ou pessoas que possuem alimentos disponíveis
para doação, como:

- Supermercados;
- Restaurantes;
- Feirantes;
- Produtores;
- Outros possíveis doadores.

O doador poderá utilizar o chat para informar os alimentos
disponíveis, suas quantidades e prazos de validade.

### ONGs

São organizações, abrigos e instituições que necessitam de
alimentos para atender pessoas em situação de vulnerabilidade.

O sistema deverá auxiliar na identificação de doações disponíveis
e no direcionamento logístico dos alimentos.

## 3. Intenções tratadas

O sistema trabalhará inicialmente com as seguintes intenções:

- cadastrar_doacao
- solicitar_alimentos
- consultar_status
- fora_de_escopo

### cadastrar_doacao

Utilizada quando o usuário deseja informar uma nova doação
de alimentos.

### solicitar_alimentos

Utilizada quando uma ONG ou organização deseja solicitar alimentos.

### consultar_status

Utilizada para consultar informações relacionadas ao status de
uma doação ou processo.

### fora_de_escopo

Utilizada quando a mensagem do usuário não estiver relacionada
às funcionalidades do MESAFARTAI.

## 4. Dados coletados pelo chat

Durante a interação com o sistema, poderão ser identificadas
informações relacionadas à doação, como:

- Tipo de alimento;
- Quantidade;
- Unidade ou peso;
- Data ou prazo de validade;
- Horário informado pelo usuário;
- Informações necessárias para o direcionamento da doação.

A extração de informações será realizada utilizando técnicas de
Processamento de Linguagem Natural e Regex.

## 5. Identidade Visual

O logotipo do MESAFARTAI foi criado utilizando Inteligência Artificial.
A proposta visual combina conceitos de alimento e acolhimento com
tecnologia e Inteligência Artificial assistiva.

### 6. Prompt utilizado

Crie um logotipo moderno e profissional para o sistema MESAFARTAI,
uma plataforma de logística e inteligência assistiva no combate à fome.
O logo deve combinar elementos que representem alimentos, acolhimento,
solidariedade e tecnologia/Inteligência Artificial. Crie um símbolo
simples, moderno e memorável, transmitindo esperança, conexão,
inovação e impacto social. Estilo minimalista e tecnológico, adequado
para uma aplicação web e projeto acadêmico. Fundo limpo e composição
profissional.
